## Pitfalls and fixes (all committed)

1. **pip 22.0 lacks PEP 660** — `pip install -e .` fails with a missing build_editable hook. → `pip install -U pip` first.
2. **Placeholder IPs in inventory + ssh-to-self denied** — preflight all rc=255. → measured values into inventory; own pubkey into own authorized_keys.
3. **Weights dir name ≠ model name** — `/raid/model_hub/GLM-5.2-FP8` vs `name: glm-5.2`; the rendered --model-path did not exist. → `ModelSpec.local_dir` (`2b4ff64`).
4. **Image UNPINNED** — the template fallback `tokiln/sglang-glm52:dev` does not exist. → verified GlmMoeDsa support in the nightly, pinned in VERSIONS.lock (`247cc33`).
5. **Stale dynamo.frontend holding port 8000** — a 7-day-old process whose workers were long gone. → killed; GPU leftovers are judged via `nvidia-smi --query-compute-apps`.
6. **streaming probe false FAIL** — during the thinking phase GLM-5.2 puts every delta in `reasoning_content`; the probe only counted `content` → chunks=0. → count both (`f1ac6b5`).
7. **tool_calls always empty though finish_reason=tool_calls** — the configured glm45 maps to sglang's deprecated `glm` parser, which cannot parse GLM-5.2's `<tool_call>name<arg_key>k</arg_key><arg_value>v</arg_value>` format; server-side template auto-detect explicitly says glm47. → `tool_call_parser: glm47` (`f1ac6b5`). **Lesson: probes assert structured fields (not raw text) precisely to catch this half-broken state.**
8. **cancel probe's 15s grace too strict** — measured: sglang aborts ~35-40s after disconnect (bounded, not a leak). → 60s grace + report the measured drain_s (`cd59557`).
9. **aa-loadgen falsely reports 82% err** — the ok-condition required a `delta.content` chunk; short replies (60% of requests, osl 20-120) stream only reasoning_content → ttft=None → err. Failure reasons were also swallowed entirely, leaving a bare counter. → reasoning compat + `err_reasons` prefix-clustered into the report (aa-loadgen).
10. **report KEYS contract drift** — `ttft_p95`/`req_ok` vs actual `ttft_p95_s`/`requests_ok`; half the report was None. → aligned + pinned by a contract test (`1894ea2`).
